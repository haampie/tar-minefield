# Security

This repository is a test suite. An archive that makes an implementation write outside its
destination, or extract other files than a scanner saw, is a vulnerability in that implementation,
not in this repository.

## A vulnerability in an implementation

Report it privately to the project itself, as its security policy says: often a `SECURITY.md`, a
security contact, or GitHub's private vulnerability reporting. Don't open an issue or pull request
here with a case or a result that shows it before the project has fixed it or its disclosure
deadline has passed: everything in this repository is public, the comparison of implementations
included.

Once it is disclosed, a case is welcome, with a link to the advisory.

## A vulnerability that affects many implementations

If a case affects several implementations, or you don't know whom to tell,
[report it here privately](https://github.com/haampie/tar-minefield/security/advisories/new), and
we coordinate the disclosure with each project.

## A vulnerability in this repository

For a problem in the scripts or the site themselves,
[report it here privately](https://github.com/haampie/tar-minefield/security/advisories/new) too.
