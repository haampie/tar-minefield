N44-pax-path-name-empty: must accept, and extract its tree

A regular file with an empty name field and a pax `path`.

The archive has a regular file, of typeflag `0`, with an empty name field. Its pax header has
`path=a`.

The pax `path` overrides the name and prefix fields, so the empty name field is not used,
and the file is `a`.

Seen in: none of the scanned tarballs.
