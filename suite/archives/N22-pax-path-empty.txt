N22-pax-path-empty: must reject

An empty pax `path`, which in POSIX removes the path rather than giving one.

POSIX says that a record with an empty value deletes the field of that name, in the header too, so
`path=` leaves the member with no name at all, not even that of its header, `from-header`. It does
not say what a member without a name is. This case is ambiguous because the name is either the
header's after all, or empty, which names the destination itself.

Decision point: what an empty pax path means: no name, an empty name, or the header's name.
Seen in: no source tarball.
