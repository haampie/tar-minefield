F01-number-leading-space: must accept, and extract its tree

Numeric fields padded with spaces rather than zeros, as old tars wrote them.

Seen in: hundreds of tarballs, many from CPAN.

0x000000  header: regular file
          name     [  0,100)  "a" + 99 NUL
          mode     [100,108)  "   644 " + NUL
          uid      [108,116)  "     0 " + NUL
          gid      [116,124)  "     0 " + NUL
          size     [124,136)  "          7 "
          mtime    [136,148)  "          0 "
          chksum   [148,156)  "006345\0 "  3301: the unsigned sum of the header, this field as spaces
          typeflag [156,157)  "0"  regular file
          linkname [157,257)  100 NUL
          magic    [257,263)  "ustar" + NUL
          version  [263,265)  "00"
          uname    [265,297)  32 NUL
          gname    [297,329)  32 NUL
          devmajor [329,337)  "0000000" + NUL  0
          devminor [337,345)  "0000000" + NUL  0
          prefix   [345,500)  155 NUL
          pad      [500,512)  12 NUL
0x000200  data
          7 bytes, then 505 NUL to the end of the block
          "spaces\n"
0x000400  2 zero blocks: the end-of-archive marker
0x000800  end of file
