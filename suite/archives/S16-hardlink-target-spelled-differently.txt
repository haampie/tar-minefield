S16-hardlink-target-spelled-differently: tolerated: a strict parser may reject it; if it accepts it, it must extract its tree, and the default policy accepts it

A hardlink to `./a`, where the member is named `a`.

The archive has a file `a`, then a hardlink `h` whose target is `./a`.

In POSIX, a hardlink represents a file linked to another file previously archived, and
its target is in the linkname field. POSIX does not say whether the target should be
literally the name of an earlier member, or whether it can also be an equivalent path. This case is
ambiguous because `./a` is a path to the file `a`, or the name of no member, so that `h` is a
link to `a`, or an error.

Decision point: whether the target of a hardlink is a path or the name of a member.
Seen in: none of the scanned tarballs.
See also: S03, a hardlink to a member that is not in the archive, and N06, the name `./a`.
