N50-name-dot-component: tolerated: a strict parser may reject it; if it accepts it, it must extract its tree, and the default policy accepts it

A name with a `.` component, `c/./d`.

The archive has one file, `c/./d`.

The special filename dot refers to the directory that it is in, so in POSIX the
file is `c/d`. This case is ambiguous only to a reader that compares names as bytes, to which
`c/./d` and `c/d` are two names for one path. The default policy tolerates it, and normalizes the
name to `c/d`, so that a second member of that path is a duplicate.

Decision point: whether a name is normalized before it is compared with others.
Seen in: 10 of the scanned tarballs, such as besu 24.1.2 and xdaliclock 2.49.
See also: N06, the name `./a`, and N49, a name with two slashes in a row.
