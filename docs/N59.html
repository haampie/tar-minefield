N59 symlink-target-dotdot-after-symlink

A symlink whose target has .. after a component that is a symlink.

The case¶

The archive has the directories d/ and d/sub/, a file d/x, a symlink s to d/sub, then a symlink t to s/../x.

The target of a symlink is a string, which is not resolved when the link is created, so t is created with the target s/../x. When t is followed, s is resolved first, and .. is then the parent of d/sub: the link leads to d/x. A reader that normalizes the target as text removes s/.., and creates a link to x, which is not in the archive. Either target stays inside the destination.

The expected tree:
