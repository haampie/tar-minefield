The case¶

The name caf\xe9 is Latin-1, and POSIX does not say how a name in the header is encoded. This case is ambiguous because the name on disk is those bytes, café decoded as Latin-1, or the name with the byte replaced.

Decision point: how a name that is not UTF-8 is decoded.

Seen in: aspell-is 0.51.1-0 and aspell-nb 0.50.1-0.
