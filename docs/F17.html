The case¶

Every tarball that git archive writes starts with a global header whose only record is the commit, as a comment, which no implementation applies to the tree. GitHub's release tarballs are made this way, so a strict parser that rejects global headers rejects most of them.

Seen in: every tarball that git archive made, such as GitHub's release tarballs.
