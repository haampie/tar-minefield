The case¶

The magic ustar\0 is followed by the version 01, where POSIX requires 00. The default policy accepts only that version, and NULs as some Java archivers write. This case is ambiguous because a reader takes the header in one of three ways: as ustar, ignoring the version; as not in a format that POSIX defines, and stops; or as a v7 header, without the fields that ustar added, which here are empty, so that it gives the same tree.

Decision point: which format the header is in.

Seen in: none of the scanned tarballs.
