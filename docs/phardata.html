Version
PharData of PHP 8.5.12, as Composer's TarDownloader calls it

This implementation follows the default policy in 69 of 188 cases:

  • it rejects 30 of the 133 cases to reject
  • it extracts the expected tree in 23 of the 36 cases to accept
  • it accepts 13 and rejects 3 of the 19 tolerated cases

The default policy is a working draft. Where an implementation does not do as it says, that can be a choice rather than a bug.
