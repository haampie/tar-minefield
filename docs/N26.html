The case¶

The first global header has path=global-name, which in POSIX applies to every later member. The second has path=, which deletes it again, so the file after them keeps the name in its header, a. This case is ambiguous in practice because a reader may instead take path= for an empty name, or ignore it and keep global-name.

Decision point: whether an empty value in a global header removes an earlier global value.

Seen in: none of the scanned tarballs.
