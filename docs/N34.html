N34 pax-linkpath-empty

An empty pax linkpath, which in POSIX deletes a target: the pax one, or the header's too?

The case¶

The archive has a symlink link, whose pax header has an empty linkpath=, and whose header has the target from-header.

POSIX says that a record with an empty value deletes any header block field of the same name, and that pax ignores any field of the header that a keyword overrides or deletes. No field of the header is named linkpath, which overrides linkname. This case is ambiguous because, if deletion goes by the name of the keyword, linkpath= deletes nothing in the header, and the target is from-header; if it goes by the field that the keyword overrides, it deletes the target too, and leaves a symlink without one; and if the empty value is the target, as POSIX assigns the value of a record, the symlink points to an empty path.

Decision point: what an empty pax link path means: no target, an empty target, or the header's.

Seen in: none of the scanned tarballs.
