The case¶

The name field contains a, followed by a NUL, followed by b. In POSIX, a name ends at its first NUL, so the name is a. Copied as a whole, the field is a as a C string, which ends at the first NUL, but a\0b in languages whose strings can contain a NUL, and creating the file then fails.

Decision point: where a name ends.

Seen in: no source tarball.
