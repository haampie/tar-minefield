N55 gnu-long-link-and-name

A symlink with a long name and a long target, in GNU's long link and long name headers.

Accept(draft) Every implementation must accept this archive, and extract the expected tree below.

The case¶

The archive has a GNU long link name header, of typeflag K, whose data is 120 ts, followed by a NUL. After it is a GNU long name header, of typeflag L, whose data is 120 ls, followed by a NUL. After those is a symlink, of typeflag 2, with GNU's magic, whose name and linkname fields contain the first 100 bytes of each.

The long name replaces the name field, and the long link name the linkname field, so the symlink has a name of 120 ls and points to 120 ts. GNU tar writes the two headers in this order.

Seen in: tarballs produced by GNU tar.
