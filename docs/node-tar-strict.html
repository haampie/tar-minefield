This implementation follows the default policy in 57 of 134 cases:

  • it rejects 22 of the 96 cases to reject
  • it extracts the expected tree in 18 of the 21 cases to accept
  • it accepts 15 and rejects 2 of the 17 tolerated cases

The default policy is a working draft. Where an implementation does not do as it says, that can be a choice rather than a bug.
