A directory with a long name in a pax path, then a file.

The case¶

The archive has a directory, then a file a. The pax header of the directory has a path of 120 ds, followed by a slash, and its header has the first 100 bytes of that path.

The pax path overrides the name field of the directory, and an extended header applies to the next file only: the tree is the directory and a.

Seen in: tarballs with long names from Python's tarfile and GNU tar in pax format.
