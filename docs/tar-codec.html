Rust tar-codec, as in uv

Version
tar-codec 0.0.15, with the policies of uv 0.13

This implementation follows the default policy in 65 of 78 cases:

  • it rejects 47 of the 60 cases to reject
  • it extracts the expected tree in all 8 cases to accept
  • it accepts 5 and rejects 5 of the 10 tolerated cases

The default policy is a working draft. Where an implementation does not do as it says, that can be a choice rather than a bug.
