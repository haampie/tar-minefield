Rust tar-codec, as in uv

Version
tar-codec 0.0.16, with the policies of uv 0.13

This implementation follows the default policy in 124 of 134 cases:

  • it rejects 86 of the 96 cases to reject
  • it extracts the expected tree in all 21 cases to accept
  • it accepts 7 and rejects 10 of the 17 tolerated cases

The default policy is a working draft. Where an implementation does not do as it says, that can be a choice rather than a bug.
