Rust tar-codec, as in uv

Version
tar-codec 0.0.16, with the policies of uv 0.13

This implementation follows the default policy in 165 of 188 cases:

  • it rejects 113 of the 133 cases to reject
  • it extracts the expected tree in 33 of the 36 cases to accept
  • it accepts 9 and rejects 10 of the 19 tolerated cases

The default policy is a working draft. Where an implementation does not do as it says, that can be a choice rather than a bug.

On the other 23, it does not:
