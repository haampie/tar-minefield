The case¶

GNU long names and pax headers are two ways of extending the next header, and neither format defines the other. Here a GNU long name from-gnu is followed by a pax header with only an mtime, and then by the member from-header. This case is ambiguous because the long name applies either to the next header, the pax header, and is lost, or to the next member, which is then from-gnu rather than from-header.

Decision point: whether a GNU long name applies to the next header or to the next member.

Seen in: no source tarball. No scanned tarball mixes GNU long names and pax headers for one member.
