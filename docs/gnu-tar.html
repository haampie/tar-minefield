This implementation follows the default policy in 40 of 81 cases:

  • it rejects 19 of the 60 cases to reject
  • it extracts the expected tree in all 10 cases to accept
  • it accepts all 11 tolerated cases

The default policy is a working draft. Where an implementation does not do as it says, that can be a choice rather than a bug.
