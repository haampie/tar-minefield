The case¶

The archive has a directory d with a file d/f, then a hardlink h to d.

In POSIX, a hardlink is a link to a file of any type archived before it, including a directory. On most systems, a directory cannot be linked, and a link that cannot be made is an error, or its data is restored from the original file. This case is ambiguous in practice because a reader can take the link in one of five ways. A reader that creates a member of the same kind as its target extracts an empty directory h. One that copies the target where it cannot link extracts a copy of the directory with its contents, so that the tree has h/f. One that makes a regular file of a link that it cannot create extracts an empty file h. One that skips a link that it cannot make extracts d and d/f alone, without an error. Other readers report an error.

Decision point: what a hardlink to a directory does.

Seen in: none of the scanned tarballs.
